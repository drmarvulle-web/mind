# Escopo do Projeto

## Nome
mente

## Tipo de software
Aplicativo desktop local para Windows

## Descrição
Software de mapas mentais para organizar ideias de forma visual, fluida e prática.

## Problema principal
Hoje, ideias, planejamentos e raciocínios costumam ficar espalhados em papéis, arquivos soltos ou aplicativos genéricos, sem uma estrutura visual clara.

## Objetivo principal
Permitir que o usuário crie, conecte, organize, salve e exporte mapas mentais com facilidade.

## Requisitos centrais
- funcionar localmente
- não depender de internet
- permitir edição posterior do mapa
- permitir exportação em PDF
- ter experiência visual simples e intuitiva
