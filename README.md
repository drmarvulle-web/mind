# mente

## Visão Geral
Mente é um software desktop de mapas mentais, inspirado na fluidez de ferramentas de mapeamento visual, criado para organizar ideias, estudos, planejamentos e raciocínios de forma clara e prática.

## Objetivo
Permitir que o usuário crie, edite, organize e salve mapas mentais localmente no computador.

## Características principais
- criação de mapas mentais
- edição de nós e subtópicos
- conexões visuais entre ideias
- organização por arrastar e soltar
- salvamento local do projeto
- abertura e edição posterior
- exportação do mapa em PDF

## MVP
- criar mapa
- editar nós
- conectar ideias
- mover nós
- salvar localmente em formato editável
- abrir mapas salvos
- exportar em PDF
